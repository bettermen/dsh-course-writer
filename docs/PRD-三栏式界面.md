# 虾说教材写作 · 三栏式界面重构 PRD

> 版本 v1.0 ｜ 2026-08-22 ｜ 状态：待评审

## 1. 背景与目标

当前「虾说教材写作」以**抽屉式工作台**（workshop-drawer）承载全部功能：项目选择、九阶段门禁、教案编辑、润色、诊断、资料库、知识图谱等挤在一个侧滑面板里，空间局促、层级混乱。

**目标**：重构为**三栏式编辑器布局**（类 IDE / Notion / 腾讯文档），把阶段导航、编辑区、资料库/预览拆到三个独立区域，提供沉浸式的课程编写体验。

## 2. 布局总览

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏：课程标题 + 项目切换 + 当前阶段 + 全局操作（保存/导出）          │
├────────────┬──────────────────────────────────┬───────────────────┤
│ 左栏        │ 中间                              │ 右栏               │
│ 阶段导航     │ 编辑区                            │ 资料库 / 预览       │
│            │                                  │                   │
│ · 项目列表   │ · 阶段工具栏（提交/驳回/AI 操作）  │ · Tab：资料库      │
│ · 九阶段     │ · 产物编辑器（Markdown）          │       知识图谱     │
│   门禁导航   │ · 课时切换（教案阶段）             │       预览/导出    │
│            │ · 底部状态栏（字数/达标/保存）       │                   │
└────────────┴──────────────────────────────────┴───────────────────┘
```

- 三栏宽度建议：左 240px ｜ 中 弹性 ｜ 右 320px（可拖拽调节，P2）
- 窄屏（<900px）自动折叠为原抽屉模式（降级）

## 3. 左栏：阶段导航

| 模块 | 说明 |
|---|---|
| 项目列表 | 顶部下拉/列表：切换课程项目、新建、克隆、删除 |
| 九阶段导航 | 垂直列表：选题 → 学情 → 教学目标 → 课程大纲 → 单元设计 → 课时教案 → 课件与练习 → 评估修订 → 结课 |
| 门禁状态 | 每阶段显示：🔒 锁定 / ○ 待开始 / ◐ 进行中 / ⚠ 待审 / ✓ 已通过 / ⏭ 跳过 |
| 交互 | 点击阶段 → 中间编辑区切到该阶段产物；已通过/跳过才可进入下一阶段（门禁联动） |
| 进度 | 底部显示整体进度（x/9 阶段完成） |

## 4. 中间：编辑区

| 模块 | 说明 |
|---|---|
| 阶段工具栏 | 当前阶段名 + 操作按钮：提交（commit）/ 驳回（reopen）/ 跳过（skip）/ 强制放行（force）；AI 快捷：生成 / 润色 / 诊断 / 出题 |
| 产物编辑器 | Markdown 文本编辑；按阶段预填模板（选题报告 / 学情 / 教学目标 / 大纲 / 单元 / 教案 / 课件 / 评估） |
| 课时切换 | 教案阶段专用：上一课 / 下一课 / 课时列表跳转 |
| 底部状态栏 | 字数统计、达标判定、保存状态、当前项目阶段 |

## 5. 右栏：资料库 / 预览

| Tab | 说明 |
|---|---|
| 资料库 | 知识点/术语/案例/公式/资源条目列表（按课程绑定），增删改查、关键词/常驻标记 |
| 知识图谱 | 节点-边可视化（复用现有 SVG 渲染），可刷新/生成 |
| 预览/导出 | 大纲/教案/课件只读预览；导出 txt / markdown |

## 6. 现有功能映射（不改后端，仅前端重组）

| 现有组件 | 去向 |
|---|---|
| workshop-drawer.tsx（1526 行） | 拆分为左栏/中栏/右栏三组件 |
| knowledge-graph.tsx（独立弹层） | 并入右栏「知识图谱」Tab，去掉独立弹层 |
| settings-card.tsx | 保持不变（设置页） |
| host 路由 / course_* 工具 | 全部复用，无需改动 |

## 7. 技术方案

- 在 `src/client/` 下新增三栏容器 `workshop-layout.tsx`，内部渲染 `PhaseNav`（左）/ `EditorPane`（中）/ `InspectorPane`（右）。
- 复用现有 `mountWorkshopDrawer` 的 React 挂载方式与 `/api/course-writer` 数据面。
- 移除 `knowledge-graph.tsx` 的独立弹层入口，改为右栏 Tab。
- 状态管理沿用现有组件内部 state（不引入新依赖）。

## 8. 优先级

| 级别 | 内容 |
|---|---|
| **P0** | 三栏骨架 + 左栏阶段导航（门禁状态）+ 中栏编辑区 + 右栏资料库（核心闭环） |
| **P1** | 知识图谱并入右栏 + 预览/导出 Tab + 阶段产物模板预填 |
| **P2** | 栏宽拖拽、窄屏折叠降级、主题/快捷键、键盘操作 |
